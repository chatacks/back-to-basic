# 🎯 Back to Basic

Repositório dedicado aos fundamentos de desenvolvimento web com HTML, CSS e JavaScript. Este projeto contém uma coleção de aplicações práticas que demonstram conceitos essenciais de front-end, desde páginas estáticas até aplicações interativas.

## 📚 Sobre o Projeto

Este repositório foi criado com o objetivo de revisitar e praticar os fundamentos do desenvolvimento web moderno, explorando HTML semântico, estilização CSS avançada e funcionalidades JavaScript puras (Vanilla JS), sem frameworks ou bibliotecas externas.

## 🚀 Como Usar

Cada projeto é independente e pode ser executado localmente:

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/back-to-basic.git
cd back-to-basic
```

2. Navegue até o projeto desejado:

```bash
cd nome-do-projeto
```

3. Abra o arquivo `index.html` no seu navegador preferido ou use um servidor local:

```bash
# Usando Python 3
python -m http.server 8000

# Usando Node.js (http-server)
npx http-server

# Usando PHP
php -S localhost:8000
```

4. Acesse no navegador: `http://localhost:8000`
